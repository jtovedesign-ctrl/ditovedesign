# 

현재 제작되어 있는 DITOVE 웹사이트를 기반으로 최종 수정한다.

중요:
- 현재 웹사이트는 약 90% 완성된 상태다.
- 전체 디자인을 새로 만들거나 리디자인하지 않는다.
- 기존의 레이아웃, 디자인 시스템, 타이포그래피, 컬러, 모션, 전체 톤앤매너를 최대한 유지한다.
- 아래 기획을 기준으로 정보 구조와 카피를 정리하고 필요한 섹션만 추가/보완한다.
- 불필요한 장식이나 새로운 디자인 요소를 과도하게 추가하지 않는다.
- 오늘 실제 공개 가능한 수준의 V1을 완성하는 것이 목표다.
- PC와 모바일 모두 대응한다.


==================================================
1. WEBSITE PURPOSE
==================================================

DITOVE는 단순한 개인 포트폴리오 사이트가 아니다.

목적은:

"DITOVE가 장기적으로 함께 일할 만한 이커머스 디자인 파트너라는 것을
처음 방문한 브랜드/기업/에이전시 담당자에게 설득하는 영업용 웹사이트"

이다.

방문자가 사이트를 보면서 다음 순서로 이해해야 한다.

1. 무엇을 하는 곳인가?
→ 이커머스 상세페이지 전문 디자인 스튜디오

2. 실력이 있는가?
→ Selected Work

3. 경험이 있는가?
→ 10+ Years Design Experience

4. 다른 디자이너와 무엇이 다른가?
→ 실제 이커머스 판매 경험

5. 믿고 맡길 수 있는가?
→ 기획부터 디자인까지 대표 디자이너 직접 진행

6. 실제 고객의 만족도는 어떤가?
→ Client Feedback

7. 지속적으로 함께 일할 수 있는가?
→ Long-term Partnership

8. 어떻게 연락하는가?
→ Contact

==================================================
8. IMPLEMENTATION RULE
==================================================

가장 중요하다.

현재 웹사이트는 이미 90% 완성되어 있다.

따라서:

1. 기존 코드를 먼저 분석한다.
2. 현재 디자인 시스템과 컴포넌트를 최대한 재사용한다.
3. 기존 Hero / Selected Work 등 잘 만들어진 섹션은 함부로 다시 만들지 않는다.
4. 필요한 카피와 정보 구조를 수정한다.
5. Client Feedback을 기존 디자인 언어에 맞게 추가한다.
6. Partnership 영역을 장기 외주 목적에 맞게 강화한다.
7. 전체 spacing과 section rhythm을 마지막에 정리한다.
8. 모바일 responsive 상태를 검수한다.
9. 링크와 CTA를 검수한다.
10. 공개 가능한 V1 상태로 마무리한다.

새로운 디자인을 제안하기보다
현재 완성된 사이트를 "영업 가능한 DITOVE 홈페이지"로 완성하는 것이 우선이다.


==================================================
9. DEFINITION OF DONE
==================================================

다음 질문에 모두 YES이면 작업을 종료한다.

- 첫 5초 안에 DITOVE가 무엇을 하는 곳인지 알 수 있는가?
- 이커머스 전문성이 보이는가?
- 10년 이상의 경험이 보이는가?
- 직접 판매 경험이라는 차별점이 보이는가?
- 현재 디자인 실력이 Selected Work에서 충분히 보이는가?
- 기획 가능한 디자이너라는 인상을 주는가?
- 실제 고객의 신뢰 근거가 있는가?
- 장기 외주 및 지속적인 협업이 가능하다는 것이 보이는가?
- 연락 방법이 명확한가?
- 모바일에서 정상적으로 사용할 수 있는가?

모두 YES라면 더 이상 디자인을 확장하지 말고 완료한다.
